# PoC-suite-test-Mocha
Prueba de Concepto (PoC) donde exploramos la configuración y uso de Mocha como framework de testing en un entorno moderno (React + Vite). Incluye una comparativa de experiencia de desarrollo, configuración y rendimiento frente a Jest y Vitest.
